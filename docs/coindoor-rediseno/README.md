# COINDOOR · Paquete de rediseño (Flyer 80s)

Paquete para que Claude Code implemente el rediseño. Va en el repo como `docs/rediseno/`.

| Archivo | Para qué |
|---|---|
| `CLAUDE_CODE_PROMPT.md` | El prompt para pegarle a Claude Code |
| `PLAN.md` | Plan por fases (0–7) con criterios de "listo" |
| `DESIGN_SPEC.md` | Especificación: tokens, primitivas, estados de campo, pantallas |
| `BUGS.md` | Bugs detectados en el recorrido |
| `tokens/flyer-tokens.css` | Tokens CSS + alias de las `--dos-*` actuales |
| `tokens/tokens.json` | Fuente de tokens (incluye las opciones descartadas A y B) |
| `mockups/*.html` | Maquetas navegables (abrir en el navegador) |
| `mockups/png/*.png` | Capturas de cada maqueta |

Maquetas:

1. `01-ficha-completa`: ficha lista (Arkanoid)
2. `02-ficha-en-carga`: ficha en carga (Lethal Enforcers, 60%)
3. `03-estados-de-campo`: los 7 estados de un campo
4. `04-ficha-secciones-extra`: Trucos, Reseña, Manual/Revistas, Galería
5. `05-juegos`
6. `06-nuevo-juego`
7. `07-exportar`
8. `08-sistemas`
9. `09-configuracion`

Fuente original: el design system "COINDOOR UI" en claude.ai (privado).
